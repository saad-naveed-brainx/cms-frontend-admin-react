## Summary

Admin SPA additions for organizations T6 (D-054, D-056). Introduces an Organization
switcher in the top bar, a `/organizations/new` route, grouping of sites by organization
on the Sites screen, and an "Add your first website" path for owners whose organization
has no site yet. Session state gains `organizations` and `organizationId`, backed by a new
`cms-admin.org` storage key, with a `pickWorkspace` helper that stays backwards-compatible
with an API that predates organizations (both `Profile.organizations` and
`Membership.site.organizationId` are optional in `isProfile`; a half answer is "cannot
check"). `useSignedIn` exposes `organizationId` and updates `ownsAnOrganization` to also
cover owned organizations with no site. `NewSite` now opens with the current/`?organization=`
organization pre-selected via `useSearchParams`. Includes a large new e2e spec
(`organizations.spec.ts`) covering switcher behavior, new-organization flow, grouped
Sites screen, and legacy-API fallback, plus mock-API extensions for organizations and
site deletion.

Stack: React 19 + TypeScript + Vite + react-router (data router). Reviewed against
react.md and the general criteria.
